# LP / Site — Login — Roteamento por Perfil

## Objetivo
Evitar confusão entre usuário, parceiro e operador.

## Rotas
- usuário final -> app stores / universal link
- parceiro -> Portal do Parceiro
- operador -> Painel Operador

## Regras
- não misturar tudo em uma única tela confusa
- textos explícitos por perfil
- CTA principal diferente por perfil
