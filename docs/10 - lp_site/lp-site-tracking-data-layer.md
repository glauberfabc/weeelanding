# LP / Site — Data Layer de Tracking

## Objetivo
Definir o objeto padrão de eventos para analytics.

## Campos base
- event_name
- page_name
- page_type
- audience
- category
- campaign_id
- utm_source
- utm_medium
- utm_campaign
- device_type
- timestamp

## Boas práticas
- payload consistente
- nomes padronizados
- evitar campos ambíguos
- documentar todos os eventos
