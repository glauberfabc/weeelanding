# LP / Site — Critérios de aceite por página

## Objetivo
Definir quando cada página pode ser considerada pronta.

## Home
Pronta quando:
- explica o produto em segundos
- separa usuário e parceiro
- tem CTA forte
- mostra categorias centrais
- funciona bem no mobile

## Como funciona
Pronta quando:
- fluxo do usuário está claro
- fluxo do parceiro está claro
- não depende de texto longo

## Categorias
Pronta quando:
- mostra benefício
- mostra subserviços principais
- leva a CTA coerente

## Para parceiros
Pronta quando:
- explica como entrar
- explica como ganhar dinheiro
- explica como funciona repasse e operação
- tem CTA claro

## Download
Pronta quando:
- links para stores estão visíveis
- QR code e preview funcionam bem
- proposta de valor é clara

## FAQ
Pronta quando:
- responde objeções principais
- evita ambiguidade
- reduz necessidade de suporte básico

## Legais
Pronta quando:
- páginas estão publicadas
- links estão visíveis
- versão e vigência aparecem

## Campanhas
Pronta quando:
- objetivo da página está claro
- CTA principal está alinhado ao tráfego
- tracking está configurado

## Critérios globais
- boa leitura em mobile
- navegação rasa
- CTA coerente por público
- nenhum texto crítico escondido
- links funcionando
