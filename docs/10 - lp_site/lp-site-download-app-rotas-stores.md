# LP / Site — Download do App — Rotas para Stores

## Objetivo
Definir a lógica de envio para lojas e fallback.

## Rotas
- Android → Google Play
- iOS → App Store
- desktop/mobile web → página intermediária se necessário

## Regras
- detectar dispositivo
- permitir escolha manual
- manter link alternativo/QR Code
- rastrear clique e envio

## Critérios de aceite
- usuário sempre encontra um caminho de instalação
