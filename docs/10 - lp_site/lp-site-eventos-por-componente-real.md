# LP / Site — Eventos por Componente Real do Front

## Objetivo
Traduzir tracking para componentes reais.

## Componentes
- HeroSection
- CategoryCards
- PartnerCTASection
- FAQAccordion
- DownloadButtons
- FooterNav
- CampaignForm

- `category_card_click`
- `partner_form_start`
- `partner_form_submit`
- `faq_item_open`
- `store_badge_click`
