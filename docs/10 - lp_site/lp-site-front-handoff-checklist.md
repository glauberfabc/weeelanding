# LP / Site — Checklist de Handoff para Front

## Objetivo
Garantir que o front receba tudo de forma executável.

## Checklist
- rotas definidas
- componentes definidos
- copy final disponível
- metadata disponível
- tracking especificado
- states definidos
- regras de CTA claras
- dependências de formulário claras
- critérios de aceite por página disponíveis
