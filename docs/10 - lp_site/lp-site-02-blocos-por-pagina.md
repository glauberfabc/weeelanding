# LP / Site — Blocos por página

## Objetivo
Definir a composição de conteúdo de cada página principal do site da WeeeMob.

## Home
1. Hero
2. Barra de confiança
3. Categorias principais
4. Como funciona
5. Benefícios para usuário
6. Benefícios para parceiro
7. Prova social
8. FAQ resumido
9. CTA final

## Como funciona
1. Hero curto
2. Fluxo do usuário
3. Fluxo do parceiro
4. Pagamento e repasse
5. Reviews, qualidade e suporte
6. CTA contextual

## Categorias
1. Hero da categoria
2. O que resolve
3. Subserviços mais comuns
4. Como contratar
5. Benefícios
6. CTA de baixar app

## Para parceiros
1. Hero para captação
2. Como funciona entrar
3. O que o parceiro controla
4. O que a plataforma controla
5. Como funciona o repasse
6. Benefícios comerciais
7. FAQ do parceiro
8. CTA de cadastro/interesse

## Download do app
1. Hero
2. Badges das stores
3. QR code
4. Preview do app
5. Benefícios rápidos
6. CTA final

## FAQ
1. Busca ou categorias de dúvidas
2. Usuário
3. Parceiro
4. Pagamento
5. Segurança/privacidade
6. CTA de contato

## Contato
1. Hero curto
2. Formulário
3. Canais por assunto
4. Endereço/redes, se houver

## Páginas legais
1. Cabeçalho legal
2. Meta de vigência/versão
3. Conteúdo estruturado
4. Contato para dúvidas

## Regras de blocos
- cada bloco precisa ter um objetivo único
- evitar blocos redundantes
- priorizar escaneabilidade
- CTA principal não pode sumir da página

## Entregáveis
- lista final de blocos por página
- objetivo por bloco
- ordem recomendada
- dependência entre blocos
