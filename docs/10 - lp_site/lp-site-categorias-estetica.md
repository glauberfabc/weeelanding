# WeeeMob — LP / Site — Categoria Estética

## Objetivo
Converter usuários interessados em estética automotiva e captar parceiros desse segmento.

## Estrutura
- Hero da categoria
- Lista de subserviços exemplo
- Benefícios para usuário
- Como contratar
- Benefícios para parceiro
- CTA para baixar app
- CTA para virar parceiro

## Subserviços exemplo
- Lavagem
- Polimento
- Higienização
- Vitrificação
- Cristalização

## Regras
- mostrar benefício visual e conveniência
- reforçar comparação por preço, nota e localização
- usar imagens e exemplos que transmitam cuidado e acabamento

## KPIs
- CTR para app
- leads de parceiro estética
- scroll qualificado
