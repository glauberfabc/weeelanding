# LP / Site — Metadata de Campanhas e URLs

## Objetivo
Padronizar títulos, descriptions e URLs de campanhas.

## Padrão de URL
- /estetica/[cidade]
- /mecanica/[cidade]
- /estacionamento/[cidade]
- /parceiros/[categoria]/[cidade]
- /campanhas/[slug]

## Campos por página
- title
- meta description
- og:title
- og:description
- canonical
- robots
- utm defaults quando aplicável
