# WeeeMob — LP / Site — Como Funciona

## Objetivo
Explicar o fluxo da plataforma para:
- usuário final
- parceiro/prestador

## Estrutura sugerida
### Usuário
1. Escolha a categoria
2. Escolha o serviço
3. Compare parceiros
4. Pague pela plataforma
5. Acompanhe e avalie

### Parceiro
1. Cadastre-se
2. Envie documentos
3. Publique ofertas
4. Receba pedidos
5. Acompanhe repasses e reputação

## Regras
- máximo de 5 passos por trilha
- sem texto longo
- usar cards ou linha do tempo visual
- cada trilha com CTA próprio

## KPIs
- taxa de scroll até fim da seção
- clique nos CTAs após leitura
- mapa de calor dos passos

## Dependências
- modelo operacional
- regras de negócio
- portal do parceiro
- app do usuário
