# LP / Site — Categoria Estética — Taxonomia

## Objetivo
Estruturar os grupos de serviço de estética automotiva para comunicação no site.

## Subgrupos sugeridos
- lavagem
- higienização
- polimento
- cristalização
- revitalização
- detalhamento

## Informação mínima por subgrupo
- nome
- descrição curta
- resultado percebido
- exemplos de oferta

## Regras
- taxonomia alinhada ao catálogo mestre
- sem termos técnicos em excesso
- fácil entendimento para leigo

## Critérios de aceite
- qualquer usuário entende a diferença entre os grupos
