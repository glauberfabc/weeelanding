## Premissas congeladas

- WeeeMob é uma plataforma operadora de marketplace para serviços automotivos.
- A LP / Site serve para captar usuário final e parceiro/prestador.
- A UX precisa ser limpa, mobile-first, com forte foco em conversão.
- As 3 categorias centrais são: **Estética**, **Mecânica** e **Estacionamento**.
- A landing deve separar claramente os caminhos de **usuário**, **parceiro** e **login**.
