# WeeeMob — LP / Site — Login / Acessos

## Objetivo
Separar claramente os acessos do ecossistema.

## Entradas oficiais
- Usuário final → app / stores
- Parceiro → Portal do Parceiro
- Time WeeeMob → Painel Operador

## Estrutura
- Seletor de perfil
- Bloco parceiro
- Bloco plataforma
- Links de ajuda
- FAQ curta de acesso

## Regras
- não misturar acessos
- não mandar usuário final para painel web por engano
- deixar o destino de cada perfil inequívoco

## KPIs
- clique por perfil
- erro de roteamento
- taxa de sucesso no primeiro clique
